⭐ PART 3 — Where AI Struggles
(and Why Senior Engineers Matter)

AI accelerates — but it doesn't understand production.
It helped a lot — but it also missed things that only experience catches.

Edge Cases

AI suggested basic heartbeat handling but missed a key nuance: stale detection must be per‑channel, not global.

My initial implementation cleared all stale flags when any message arrived.
That keeps the UI green — but it hides channel‑specific failures.

Bitfinex channels can fail independently, so each subscription needs its own stale timer.

That's the kind of detail you only learn by shipping real systems.

Performance Trade‑offs

AI defaulted to slice() everywhere.
I knew splice() was better for high‑frequency, in‑place updates.

API Quirks

Bitfinex sends different formats for snapshots vs updates.

AI understood the idea, but not the exact formats — for example:

  • Snapshot: [channelId, [trade1, trade2]]
  • Update: [channelId, 'te', trade]

These quirks matter. They break your parser if you don't know them.

Memory Management

AI didn't understand memory‑bounded arrays.

Without limits, 8 hours of trading data becomes:
288,000 updates × 10 pairs = a multi‑GB memory leak.

The app enforces:

  • MAX_TRADES = 1000
  • MAX_CANDLES = 5000

This keeps memory stable at ~60MB instead of creeping past 2GB and crashing.

Production Concerns AI Didn't Consider

  • Handler‑based architecture (trades, tickers, candles, book)
  • 90‑second stale timeouts with 30‑second monitoring intervals
  • Exponential backoff (5 attempts, increasing delays)
  • Performance tracking via performanceTracker.updateLatency()
  • Environment‑configurable limits (VITE_MAX_TRADES)

These aren't "nice to haves" — they're what keep real‑time systems alive.

The Reality

Building a crypto trading dashboard made one thing clear:

AI is incredible at scaffolding — but production‑grade real‑time systems require architectural judgment that only comes from experience.

AI accelerates — but it doesn't understand production.
That's where senior engineers still make the difference.
