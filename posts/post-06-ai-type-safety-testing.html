⭐ PART 2 — Type Safety, Testing & Performance Optimisation
(with AI as a Junior Partner)

Real‑time systems fall apart without strict typing, solid tests, and predictable performance.
Here's how I used AI to accelerate the "boring but critical" parts of engineering.

6. Type Safety: AI Generates TypeScript Definitions

WebSocket streams demand strict typing for reliability and safe refactoring.

Prompt:

"Create TypeScript types for Bitfinex WebSocket API v2:
  • Subscription messages
  • Channel types
  • Trade data
  • Candle data
  • Order book data

AI generated clean enums and interfaces for:

  • TRADES, TICKER, CANDLES, BOOK
  • Subscription messages
  • Raw trade tuples vs normalized objects

I adjusted a few fields to match the real API.

Time saved: ~2–3 hours.

7. Testing: AI Writes Unit Tests

Memory‑bounded reducers are easy to get wrong under load.

Prompt:

"Write Vitest tests for memory‑bounded trades reducer:
  • Enforce MAX_TRADES
  • Remove oldest trades
  • Keep newest trades

AI generated a full test suite that:

  • Pushed 1,500 trades
  • Asserted only the last 1,000 remained
  • Checked first and last IDs

I aligned it with my reducer signature.

Time saved: ~4–5 hours.

8. Performance — AI Helps Simplify, Not Over‑Engineer

In real‑time UIs, it's tempting to over‑engineer performance. For CryptoApp, I kept it simple and used AI to validate the approach.

Prompt:

"Order book UI feels heavy under constant updates. Suggest lightweight performance strategies for React + AG Grid."

AI suggested several options (batching, debouncing, transactional updates), but for this app I went with:

  • A 100ms useThrottle on incoming order updates
  • A memory‑bounded order book with MAX_BOOK_ORDERS = 100
  • Standard rowData updates into AG Grid

That was enough to keep the grid smooth and responsive without adding complexity I didn't need.

Time saved: ~1 day of trial‑and‑error and premature optimisation

⭐ Real Results

CryptoApp:

  • 5,000+ LOC
  • Built in ~5 days (vs 3–4 weeks)
  • 60 FPS stable
  • ~60MB memory after 8 hours
  • Handler‑based, memory‑bounded, monitored, production‑ready

Note: These time‑savings are experience‑based estimates. AI sped up the repetitive work — the real engineering still came from me.
